# 「可」抖音宣传海报设计

## 目标

为 macOS 开源工具「可」制作一张抖音竖版宣传海报，主要吸引 Mac 与 AI
工具重度用户。海报需在信息流中快速建立识别，并把用户导向
`https://github.com/chilltongx/ke`。

## 已选方向

采用 A「一字成令」。以巨大的圆形“可”印章为唯一主视觉，延续 App
图标的煤灰底、米白字和薄荷绿光环。背景只加入极淡的光标轨迹与信号环，
保持克制，不使用人物、设备照片、第三方商标或装饰性插画。

## 画布与版式

- 画布：1080 × 1920 PNG，9:16。
- 安全边距：四边至少 72 px，避免抖音 UI 遮挡核心信息。
- 顶部：小号英文标识，作为技术感视觉刻度。
- 中上部：大尺寸圆形“可”印章，视觉中心约位于画布高度 31%。
- 中部：主标题与副标题，居中排列。
- 中下部：支持应用文字列表，仅作信息锚点。
- 底部：开源提示、仓库地址与真实二维码。

## 准确文案

所有文字必须逐字呈现，不得由生成模型改写或新增：

```text
MACOS · OPEN SOURCE

一键，可。
光标在哪，就发到哪

CODEX · VS CODE · 微信

扫码开源免费用
github.com/chilltongx/ke
```

## 视觉系统

- 煤灰：`#1E1E1F`，主背景与印章底色。
- 深黑：`#111314`，背景暗部。
- 米白：`#F6F7F8`，主字与标题。
- 薄荷绿：`#55D6BE`，光环与唯一高亮色。
- 次级灰：`#919996`，说明文字与刻度。
- 中文使用苹方或系统黑体粗体；英文与仓库地址使用清晰的等宽无衬线体。

## 制作方式

生成式图像仅用于低对比度背景纹理。主视觉“可”、全部文案、App 图标和二维码
使用确定性本地绘制，保证汉字、URL 与二维码准确。二维码内容固定为
`https://github.com/chilltongx/ke`，不得使用生成式二维码。

## 交付与验收

- 最终文件：`marketing/ke-douyin-poster.png`。
- 视觉哲学：`marketing/ke-poster-visual-philosophy.md`。
- PNG 尺寸必须为 1080 × 1920，文字无错字、无裁切、无重叠。
- 二维码需通过本地解码验证并直达仓库。
- 海报需保留清晰视觉层级：先看到“可”，再看到“一键，可。”，最后看到导流信息。
- 不添加水印、App Store 标识、虚假下载量或未经授权的第三方 Logo。
